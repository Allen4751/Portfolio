# Personal Portfolio Website

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Before publishing
1. Confirm the display name and professional title in `index.html` (currently shown as Allen / Independent Web Developer).
2. Replace `YOUR-EMAIL@example.com` in the contact section with a real email address.
3. Confirm that both project links are still live and that the project descriptions accurately represent your contribution.
4. Add a real contact method (email or WhatsApp) before sharing the portfolio with prospective clients.

## Deploy to Netlify
Drag the extracted `allen-portfolio` folder into Netlify Drop, or connect the folder/repository to a Netlify site. The site is static and needs no build command. Publish directory: `.`

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and current year
- `assets/images/` — project image used in the Rhena Schools card
